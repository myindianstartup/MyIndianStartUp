# 💳 Razorpay Live Integration Guide — MyIndianStartup

This guide outlines the step-by-step procedure to transition from the current demo checkout flow to a fully operational, live **Razorpay** payment gateway integration.

---

## 📋 Prerequisites & Credentials Needed
Before starting, the client must set up a Razorpay business account and generate API keys:
1. Register/Login at [razorpay.com](https://razorpay.com).
2. Complete KYC/activation to enable live payments.
3. Navigate to **Account & Settings** → **API Keys** → **Generate Key**.
4. Retrieve the following credentials:
   * `Key ID` (e.g., `rzp_live_XXXXXXXXXXXXXX` or `rzp_test_XXXXXXXXXXXXXX`)
   * `Key Secret` (e.g., `XXXXXXXXXXXXXXXXXXXXXXXX`)

## 🔌 Step 4: Backend Order Creation Integration
Install the official Razorpay SDK in the backend folder:
```bash
npm install razorpay
```
In `backend/src/services/billingService.js`, import the SDK and initialize it:
```javascript
import Razorpay from 'razorpay';

const razorpay = new Razorpay({
  key_id: process.env.RAZORPAY_KEY_ID,
  key_secret: process.env.RAZORPAY_KEY_SECRET
});
```

Update `createCheckoutOrder` to create a real order ID via the SDK instead of a mock UUID:

## 🔒 Step 5: Webhook Signature Verification (Production Best Practice)
To prevent forged payment alerts, verify webhook signatures on the webhook endpoint.
In `backend/src/routes/subscriptions.js`:

```javascript
import crypto from 'node:crypto';

subscriptionsRouter.post('/razorpay/webhook', async (req, res, next) => {
  try {
    const signature = req.headers['x-razorpay-signature'];
    const webhookSecret = process.env.RAZORPAY_WEBHOOK_SECRET;

    if (webhookSecret && signature) {
      const expectedSignature = crypto
        .createHmac('sha256', webhookSecret)
        .update(JSON.stringify(req.body))
        .digest('hex');

      if (expectedSignature !== signature) {
        return res.status(400).json({ error: 'Invalid webhook signature.' });
      }
    }
    
    // Existing capture-and-activation logic remains unchanged...
  } catch (error) {
    next(error);
  }
});
```

## 📡 Step 6: Configure Razorpay Webhook URL
Configure Razorpay to notify the backend of successful payments:
1. Go to **Razorpay Dashboard** → **Settings** → **Webhooks** → **Add New Webhook**.
2. **Webhook URL:** `https://your-backend-domain.com/api/subscriptions/razorpay/webhook`
3. **Secret:** Set a custom secret key (add to backend `.env` as `RAZORPAY_WEBHOOK_SECRET`).
4. **Active Events:** Select `payment.captured` and `payment.failed`.
